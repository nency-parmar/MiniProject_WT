# 🌍 Travel Website

A modern travel website built using the **MERN Stack** to explore destinations and manage travel-related information.

## ✨ Features

- 🌎 Explore travel destinations
- 🏨 View travel-related information
- 🔐 User authentication
- 📱 Responsive design
- ⚡ Fast and interactive UI
- 🗄️ MongoDB database integration

## 🛠️ Tech Stack

| Technology | Used For |
|-----------|----------|
| ⚛️ React.js | Frontend |
| 🟢 Node.js | Backend |
| 🚂 Express.js | Server & APIs |
| 🍃 MongoDB | Database |
| 🎨 CSS | Styling |
| 🔧 Git & GitHub | Version Control |
